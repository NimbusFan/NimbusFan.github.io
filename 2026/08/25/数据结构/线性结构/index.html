线性结构：栈、队列、双端队列与列表

线性结构概述

线性结构中的数据元素按照一定顺序排列，元素之间存在明确的前后关系。

除首尾元素外，每个元素通常都有：

  • 唯一的前驱元素；
  • 唯一的后继元素。

栈、队列和双端队列都可以看作对列表操作位置进行限制后形成的数据结构。

结构 允许操作的位置 核心规则
列表 任意位置 按位置组织元素
栈 同一端 后进先出(LIFO)
队列 两端分工 先进先出(FIFO)
双端队列 两端均可操作 两端进、两端出

队列 Queue

定义

队列从一端加入元素，从另一端删除元素。

  • 加入元素的一端：队尾；
  • 删除元素的一端：队首。

dequeue() 从队首删除并返回元素
isEmpty() 判断队列是否为空
size() 返回队列长度

  • 任务排队；

双端队列 Deque

定义

双端队列允许在队首和队尾两端添加、删除元素。

它同时具备栈和队列的部分功能。

主要操作

操作 含义
append(item) 右端加入
appendleft(item) 左端加入
pop() 右端删除
popleft() 左端删除

Python 实现

deque 两端的添加和删除通常都是 O(1)。

常见应用

  • 普通队列；
  • 栈；
  • 回文判断；
  • 滑动窗口；
  • 单调队列。

列表 List

定义

列表是一组按照位置排列的数据元素。
与栈和队列不同，列表通常允许在任意位置：

  • 添加元素；
  • 删除元素；
  • 查询元素；
  • 修改元素；
  • 遍历元素。

常见操作

操作 含义
add(item) 添加元素
remove(item) 删除元素
search(item) 查找元素
isEmpty() 判断是否为空
size() 获取元素数量
append(item) 在末尾添加元素
insert(index, item) 在指定位置插入元素
pop(index) 删除指定位置元素
index(item) 查找元素的位置

Python 列表

Python 的 list 底层属于动态数组，因此：

  • 下标访问速度快；
  • 尾部添加、删除速度快；
  • 首部或中间插入、删除速度较慢。

Python 常用操作复杂度

操作 时间复杂度
list[index] O(1)
list.append(x) 平均 O(1)
list.pop() O(1)
list.insert(0, x) O(n)
list.pop(0) O(n)
x in list O(n)
deque.append(x) O(1)
deque.appendleft(x) O(1)
deque.pop() O(1)
deque.popleft() O(1)

四种结构对比

数据结构 操作规则 Python 常用实现 典型应用
栈 后进先出 list 括号匹配、DFS、单调栈
队列 先进先出 deque BFS、任务调度
双端队列 两端均可进出 deque 滑动窗口、单调队列
列表 可按位置操作 list 数据存储、随机访问
