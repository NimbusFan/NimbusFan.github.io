关于

你好，我是 樊云飞（Yunfei Fan）。

我本科毕业于 河海大学地理信息科学专业，目前就读于 华东师范大学测绘工程专业。当前主要关注 SLAM、算法与 GIS，正在开发视觉检索与轨迹分析项目 OmniSearch。

我关注的问题是：
如何让现实世界中的空间对象、视频流、地理数据和多模态信息，被机器理解、检索和推理。

技术栈

C++ Python Java Spring Boot MySQL PostgreSQL MinIO FastAPI PyTorch OpenCV Docker Git

当前方向

我的兴趣主要集中在以下几个方向：

  • 多模态检索：将图像、视频、文本和空间信息统一到可检索的语义空间中。
  • SLAM 与空间数据：关注定位、地图表达和 GIS 分析中的算法与数据处理。
  • 后端系统设计：使用 Java / Spring Boot 构建稳定、可扩展的数据调度与检索服务。
  • AI 工程化落地：将深度学习模型封装为可调用、可部署、可维护的工程模块。
  • 数据库与向量检索：基于 PostgreSQL、MySQL 和向量数据库能力构建结构化与非结构化数据检索系统。

项目经历

OmniSearch

OmniSearch 面向多摄像头场景，以 C++ 为主要开发语言，将视频采样、行人检测、特征提取和数据库检索连接起来。

目前已完成小规模以图检索、单摄像头短视频跟踪和代表图入库；多路采集调度、文字检索与跨摄像头轨迹重建仍在开发和验证中。技术栈与具体进展见项目记录。
